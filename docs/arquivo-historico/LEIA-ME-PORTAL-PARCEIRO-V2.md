# Portal Parceiro V2

Patch visual do Portal Parceiro.

## Alterações
- CTS: substitui progresso acumulado (ex.: 790%) por ciclos concluídos e progresso para o próximo benefício.
- ItaPharma: destaca repasse fixo por unidade em vez de tratar a porcentagem de referência como comissão fixa.
- Parcerias por brinde/repasse deixam de exibir estimativa financeira mensal enganosa.
- Pontos consignados sem saldo mostram que o estoque está aguardando conferência.

## Instalação
Extraia este ZIP sobre a raiz do projeto `candinho-gestao`, mantendo a estrutura de pastas, e confirme a substituição do arquivo existente.
Depois faça Commit e Push pelo GitHub Desktop.
