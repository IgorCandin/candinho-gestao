# Ajuste de UX — Produtos da Candinho Fitness

Este pacote deixa a área de Produtos da Fitness mais simples e visual.

## Alterações

- Remove os três cards de métricas do topo da tela de Produtos.
- Catálogo passa a abrir em **Fotos** por padrão.
- Remove o controle de zoom/tamanho dos cards e o botão Completo/Essencial.
- Grade fica fixa e responsiva: mais confortável no celular.
- Lista reduzida para:
  - Produto
  - Disponível
  - A caminho
  - Preço
  - Situação
- Cards de foto mostram apenas o necessário para escolher uma peça.
- Ao abrir o produto, a foto aparece grande.
- Tocando na foto abre um visualizador com:
  - ampliar
  - reduzir
  - resetar
  - fechar
- Tela do produto mostra primeiro uma tabela simples de tamanhos e cores.
- SKU, estoque físico, reservado e custo ficam em **Ver dados completos de estoque e custo**, fechado por padrão.

## Como aplicar

Extraia o ZIP na raiz do projeto `candinho-gestao`, substituindo os arquivos quando o Windows perguntar.

Depois, no GitHub Desktop:
1. confira os arquivos alterados;
2. Summary: `Simplifica produtos Fitness e adiciona zoom nas fotos`;
3. Commit to main;
4. Push origin.

Não há migration de banco neste pacote.
