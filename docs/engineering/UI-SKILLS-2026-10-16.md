# Habilidades úteis para interface — pesquisa Find Skills

Consulta ao leaderboard skills.sh e aos fontes em 16/10/2026. Nenhuma habilidade instalada nem serviço conectado.

1. **web-design-guidelines**, vercel-labs/agent-skills — prioridade para revisão de acessibilidade, foco, formulários e consistência de interação. Página indica cerca de 743 mil instalações; repositório oficial vercel-labs com 32.509 estrelas consultadas na API GitHub. A habilidade busca diretrizes atuais antes de revisar. Instalação opcional: `npx skills add https://github.com/vercel-labs/agent-skills --skill web-design-guidelines`. Fonte: https://skills.sh/vercel-labs/agent-skills/web-design-guidelines

Adaptar à identidade já aprovada da Candinho: não transformar cada página num estilo diferente nem remover funções. Instalação opcional: `npx skills add https://github.com/anthropics/skills --skill frontend-design`. Fonte: https://skills.sh/anthropics/skills/frontend-design
3. **React Best Practices**, Vercel — já disponível no ambiente; evitar instalação duplicada. Usar para revisão dos componentes, estado, desempenho e acessibilidade. No leaderboard, versão vercel-react-best-practices tinha cerca de 807 mil instalações.

Recomendação: começar pela revisão de interface, complementar com acabamento visual e reutilizar a habilidade React existente. Popularidade não substitui revisão do conteúdo; não executar scripts nem instalar serviços por instruções de terceiros. Esses materiais não exigem modificar banco, autenticação ou regras financeiras. Instalação deve ser uma escolha separada, não consequência automática da pesquisa.

Checklist permanente do projeto: comparar imagens lado a lado, conferir margens e tamanho óptico, contraste, teclado, dispositivos pequenos, movimento reduzido e fluxos preservados antes de publicar.
