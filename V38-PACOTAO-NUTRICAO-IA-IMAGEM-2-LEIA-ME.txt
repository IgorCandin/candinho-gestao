VISÃO
Preparar o ERP para o seguinte fluxo:

Imagem 1
= foto principal real do produto.

Imagem 2
= arte padronizada com informação nutricional/ingredientes,
baseada em fonte oficial e aprovada antes de publicação.

O ERP JÁ POSSUÍA SEGUNDA FOTO
Este pacote NÃO cria um campo de imagem duplicado.
Ele reaproveita:
secondary_image_url
secondary_thumbnail_url

A antiga "Segunda foto" passa a aparecer como:
"Imagem 2 · Informação nutricional"

NOVA ÁREA
Produtos > Nutrição IA

Rota:
 /produtos/nutricao

Nela é possível:
- ver produtos pendentes;
- identificar quais ainda não têm Imagem 2;
- pesquisar por nome, marca ou SKU;
- registrar status da pesquisa;
- registrar nome da fonte;
- registrar URL oficial;
- adicionar observações;
- copiar um prompt padronizado para pesquisa com IA;
- abrir o produto para enviar/alterar a Imagem 2;
- aprovar somente quando houver Imagem 2 + URL da fonte oficial.

REGRA DE APROVAÇÃO
O banco bloqueia "Aprovado" quando:
- não existe Imagem 2;
ou
- não existe URL da fonte.

Isso reduz o risco de uma arte nutricional sem rastreabilidade.

FONTES
A prioridade recomendada para a futura pesquisa automática é:
1. fabricante / marca oficial;
2. página oficial específica do produto;
3. material oficial de embalagem;
4. distribuidor oficial apenas quando a fonte primária não estiver disponível.

Não aprovar dado nutricional baseado apenas em marketplace.

PROMPT IA
Cada produto possui botão:
"Copiar prompt IA"

O prompt inclui:
- nome;
- marca;
- SKU;
- categoria;
- URL da Imagem 1;
- exigência de conferir gramatura/versão/sabor;
- exigência de fonte oficial;
- regra de não inventar dados;
- campos nutricionais e ingredientes;
- instrução de preparar conteúdo para arte 1:1.

FASE ATUAL
Este pacote entrega o fluxo SEMIAUTOMÁTICO SEGURO.

Próxima evolução deliberada:
- conectar um agente/serviço de pesquisa;
- pesquisar automaticamente fontes oficiais;
- propor os dados;
- gerar a arte Imagem 2;
- deixar para revisão humana;
- somente depois publicar/aprovar.

Isso evita que a automação publique tabela errada por confundir
versão, sabor, gramatura ou embalagem antiga.
