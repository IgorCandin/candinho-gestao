OBJETIVO
- Transformar /suplementos em uma Home orientada à pergunta “O que eu preciso fazer hoje?”.
- Simplificar o menu principal sem apagar nenhuma rota ou função existente.
- Corrigir o fluxo “Nexus · Completar informações” para usar a API interna com fallback, evitando depender diretamente da Edge Function que vinha retornando 429.
- Deixar o fluxo de Sabores mais explícito: cadastrar sabores -> distribuir estoque -> salvar.
- Tornar Parceiros mais operacional e deixar o acesso do Portal Parceiro fácil de encontrar/configurar.
- Inicializar a Physique de forma controlada: atletas, avaliações, evolução por fotos, PDF de avaliação com leitura do Nexus, ficha de treino em PDF com leitura estruturada pelo Nexus e anexos privados.

COMO APLICAR
1. Faça seu backup da pasta atual (você já planejou isso).
2. Extraia TODO o conteúdo deste ZIP na RAIZ da pasta candinho-gestao, substituindo os arquivos quando solicitado.
3. Dê dois cliques em 00_APLICAR_PACOTE.cmd.
   - O script NÃO faz commit.
   - Ele apenas ajusta dois arquivos grandes (app-shell e product-form), remove as rotas antigas da Physique que herdavam o menu do ERP e acrescenta CSS.
4. Abra o GitHub Desktop e revise todas as alterações.
5. Rode localmente:
   npm run build
   npm run lint
6. Teste os fluxos reais antes do commit.
